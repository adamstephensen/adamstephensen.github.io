# Writing a post for adamstephensen.com

## File location and name

```
_posts/YYYY-MM/YYYY-MM-DD-Title-With-Dashes.md
```

Create the `YYYY-MM/` folder if it doesn't exist yet. Jekyll takes the date from the
filename, so it must be correct. Prefer `.md`; some legacy posts use `.markdown`.

## Front matter

```yaml
---
title: "Full Title, Sentence Or Title Case, In Quotes"
permalink: /YYYY/MM/DD/url-slug-lowercase-dashes/
layout: post
tags:
  - Azure
  - AI
---
```

- `permalink` is **permanent**. Set it once, matching the post date, and never change it on
  a published post — inbound links and search results depend on it. Leading and trailing
  slash both required.
- `comments: true` appears on some older posts; it's inert, don't add it to new ones.
- Don't set `categories` — this site uses tags.

## Tags

Reuse existing tags rather than inventing near-duplicates. Most used, in order:
`Videos`, `.NET`, `Azure`, `DevOps`, `AI`, `Training`, `Visual Studio`, `Testing`, `NDC`,
`Cognitive Services`, `Agile`, `Mobile`, `JavaScript`, `Git`, `Angular`, `Travel`, `Bots`.

Check what's already in use before adding a new one:

```bash
grep -rh -A20 '^tags:' _posts | grep '^  - ' | sort | uniq -c | sort -rn
```

Note the tag index pages these feed are generated by `_plugins/_tag_gen.rb`, which
**does not run on GitHub Pages** — tag pages exist locally only.

## Images

New posts: put files in `assets/images/posts/` named after the post, numbered.

```
assets/images/posts/2026-04-14-DevGovOps-01.png
```

Reference with an absolute site path and alt text:

```markdown
<img src="/assets/images/posts/2026-04-14-DevGovOps-01.png" alt="What the image shows" class="img-responsive">
```

Markdown syntax (`![alt](/assets/images/...)`) is equally fine. Older posts use per-month
folders (`assets/images/YYYY-MM/`) — leave those alone, don't migrate them.

## Video

Paste the standard YouTube iframe directly:

```html
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" frameborder="0" allowfullscreen></iframe>
```

Do **not** use the `{% youtube %}` tag from `_plugins/` — it renders locally and produces
nothing in production. Tag video posts with `Videos`.

## Drafting and unpublishing

There is no `_drafts/` folder. Jekyll ignores any file inside `_posts/` whose name starts
with `_`, so prefix the filename with an underscore while drafting and remove it to publish:

```
_posts/2026-08/_2026-08-29-half-written-thing.md   ← invisible
_posts/2026-08/2026-08-29-half-written-thing.md    ← live on next push
```

## Voice

Australian English. First person, conversational, short paragraphs. Concrete experience over
abstraction — real projects, real numbers, what actually went wrong. Bold for the phrase that
carries the point, `##` headings to break up long pieces, blockquotes for the one-line takeaway.
Match the tone of `_posts/2026-04/2026-04-14-DevGovOps.md`.

## Before saying it's done

1. Filename date, `permalink` date and any date in the prose agree.
2. Every referenced image file actually exists on disk.
3. Preview it: `bundle exec jekyll serve` and open the post's permalink.

Publishing = committing and pushing to `main`. Only do that when asked.
